Wishes for first Lohri

Lohri is special festival. If this is first lohri it is even more special.
What is first lohri?
1. If a new baby is born in last one year, it is considered first lohri of child. The whole faily celebrates it
2. If a person in married in last one year, it is first lohri for newly weds couple.
